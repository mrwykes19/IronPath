# IronPath v6 Visual System

IronPath v6 uses the promotional concept as its visual direction while remaining practical on a phone-sized web app.

- Near-black base with electric-blue highlights
- Large contextual workout artwork integrated into feature cards
- Locally rendered equipment and phase graphics
- More dimensional metric cards and progress rings
- Designed achievement, milestone, and empty-state visuals
- No anatomy figures or external image dependencies

The artwork remains secondary to readability and workout entry. All visuals are bundled or drawn inside the application so Cloudflare can serve them as normal static app assets.
