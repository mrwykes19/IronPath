# IronPath v6

## Full visual redesign
- Rebuilt the Today workout card around a large integrated workout illustration instead of a small corner logo.
- Added visual variants for upper, lower, push, pull, and total-body sessions.
- Redesigned weekly goal rings, quick metrics, card depth, accent lighting, spacing, and typography.
- Added richer locally rendered cardio equipment graphics and a graphical cardio header.
- Refined Training Evolution phase graphics and achievement artwork.
- Preserved all v5.6 functionality, including manual cardio entry, adaptive four-phase programming, workout editing, backup/restore, and cardio progress.

## Deployment
- Graphics are bundled with the app or rendered as local vector-style React Native components.
- No remote image service or third-party image URL is required.
- Existing local IronPath data remains compatible.
