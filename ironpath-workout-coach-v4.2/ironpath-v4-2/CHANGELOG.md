# IronPath v4.2

## Goal-aware programming

- Primary Goal now actively changes future workout programming.
- Added four goal profiles: Balanced, Strength, Muscle, and Fat Loss.
- Strength emphasizes lower compound-lift rep ranges, longer rest periods, and slightly less isolation volume.
- Muscle adds working sets and uses moderate-to-high hypertrophy rep ranges.
- Fat Loss keeps the major lifts while shortening rest periods and reducing estimated session duration.
- Balanced preserves the existing mixed strength-and-muscle program.
- Changing goals requires confirmation and applies only to future workouts.
- Completed workouts and any workout already in progress remain unchanged.
- Settings now explains the active program effect before and after a goal change.
- Backup files continue to preserve the selected goal.

## Compatibility

- Keeps the existing `@ironpath/state/v1` browser-storage key.
- Existing v4 and v4.1 workout, weight, and backup data remain compatible.
