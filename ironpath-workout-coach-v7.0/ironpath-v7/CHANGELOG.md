# IronPath v7.0

- Weekly goals simplified to Total Workouts and Cardio Days.
- Active Minutes moved into Quick Metrics.
- Weeks now run Sunday through Saturday.
- Timed-cardio calories now feed the weekly Calories Burned total.
- Added Commercial Gym, Home Gym, and No Gym custom-workout environments.
- Added home/bodyweight exercises and broader substitutions.
- Removed redundant Train empty-state heading.
- Added a completed-workout Today state that remains for the day.
- Gains now emphasizes actual logged weight; estimated 1RM remains in Personal Records.
