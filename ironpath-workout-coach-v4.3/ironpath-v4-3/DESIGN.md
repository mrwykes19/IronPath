# IronPath v4.1 Design Notes

Version 4.1 retains the premium blue-on-black v4 visual system and adds a dedicated **Data & Backup** experience in Settings.

## Backup card

- Appears near the top of Settings so it is easy to find before resetting or moving devices.
- Shows the last successful backup date.
- Uses separate Export and Import actions.
- Clearly states that data remains local and is not uploaded to IronPath.

## Import review

A selected file is validated before restore controls appear. The review card shows:

- backup filename;
- export date;
- app version;
- completed workout count;
- weigh-in count; and
- whether an unfinished workout is included.

Merge and Replace are deliberately separate actions to reduce accidental data loss.
