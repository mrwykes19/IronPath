# IronPath v4.3

- Moved Data & Backup to the bottom of Settings, immediately before Reset Local Data.
- Added selectable 2-, 3-, 4-, or 5-day weekly strength programs.
- Added meaningful schedules for each frequency: two- and three-day full body, four-day upper/lower, and a five-day upper/lower/push/pull/lower split.
- Added a “Don’t Forget Cardio” tracker to Today.
- Cardio device choices include treadmill run, treadmill walk, bike, elliptical, rower, and stair climber.
- Cardio sessions track elapsed time and allow distance and notes to be entered when finished.
- Added cardio distance-per-session trends, total distance, best session, and latest improvement to Gains.
- Cardio history is stored locally and included in IronPath backups.
