# IronPath v5.0.0

## Training Evolution

- Added a selectable four-phase Training Evolution browser.
- Preview Volume Base, Build, Progress, and Peak before reaching them.
- Each phase shows its purpose, expected load change, workouts, exercises, sets, reps, and rest periods.
- The current phase is clearly marked while future phases remain available for review.
- Added a live current-phase review with workouts, adherence, completed sets, cardio distance, and readiness guidance.
- Added Advance Phase, Repeat Phase, Regenerate Current Phase, and Start Next Block controls.

## Workout naming

- Replaced the prior workout titles with clearer distinctive names:
  - Press & Pull
  - Squat & Hinge
  - Upper Build
  - Lower Build
  - Total Foundation
  - Total Progression
  - Hinge & Press
  - Total Build
  - Push Build
  - Pull Build

## Today

- Added a concise motivational quote that changes once per calendar day.
- Quotes work offline and remain stable throughout the day.

## Preserved behavior

- New users begin at Volume Base.
- Four-phase load and repetition progression remains active.
- Workout preview editing, cardio, backups, adaptive rotation, and goal-aware programming remain intact.
