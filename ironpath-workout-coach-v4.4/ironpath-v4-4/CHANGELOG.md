# IronPath v4.4

## Adaptive weekly programming

- Added My Training Week editor in Settings.
- Added Consistent, Moderate, and High workout-variety modes.
- Added four-week training blocks.
- Added automatic accessory rotation and plateau-aware exercise changes.
- Added exercise locking so favorite lifts remain in generated plans.
- Added workout renaming, exercise reordering, adding/removing exercises, swapping variations, and set-count editing.
- Future workouts use the saved weekly plan; completed history and active workouts are not changed.
- Weekly plans are included in local storage and backup exports.
